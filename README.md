# Markhor Wears - Custom Apparel Platform

A full-stack e-commerce web application and administrative solution tailored for a custom apparel brand. Designed to manage product catalogs, handle user interactions, and process backend data dynamically.

## 🚀 Tech Stack
* **Backend:** PHP (Dynamic server-side routing & business logic)
* **Database:** MySQL (Relational schema structured for products, categories, and administrative control)
* **Frontend:** HTML5, Custom External CSS (Unique, hand-crafted UI architecture built entirely without UI frameworks for complete styling control)

## 🛠️ Key Features
* **Custom UI Branding:** Designed natively with tailored CSS styles to ensure an original, high-performance visual experience.
* **Administrative Management:** Secure backend operations to manage, track, and update clothing inventory and platform options.
* **Database Efficiency:** Optimized queries interfacing with a dedicated MySQL instance to keep tracking smooth and dynamic.

## 💻 Setup Instructions
1. Clone or download this project directory.
2. Place the folder inside your local environment path (e.g., `xampp/htdocs/`).
3. Import the corresponding database schema (e.g., `mw_db.sql`) through **phpMyAdmin**.
4. Check your central configuration file to verify local database connection details match.
5. Turn on Apache and MySQL in XAMPP, then open `http://localhost/markhor-wears/` in your browser.
